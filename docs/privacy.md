# 隐私设计

轻务会接触姓名、联系方式、学号、活动照片、票据和支付凭证，因此隐私边界是产品功能，不是发布后的补充说明。

## 默认本地

事务、事实、待办、人员进度、材料路径和文案版本存入本机 SQLite。材料原文件停留在用户选择的位置。轻务不提供账号、云同步、在线收集页或遥测。

## AI 明确授权

AI 默认关闭，只在事实提取、风格卡生成或用户勾选 AI 文案时调用。每次请求只发送当前任务所需信息，并使用 `store: false`。网络或 API 失败不会阻断离线闭环。

API Key 保存于 Windows Credential Manager：

- 不进入 SQLite；
- 不返回 React；
- 不进入日志和错误消息；
- 不进入导出包；
- 可由用户随时删除。

## 历史文案

TXT、Markdown、DOCX 和可提取文本的 PDF 在本地读取。上传预览会显示样本数、字符数和疑似手机号、学号、邮箱。默认只向 AI 发送提取文本，不发送原始文件。风格卡确认后可以立即删除缓存文本。

## 归档最小化

默认导出：已确认的非敏感事实、最终文案、用户选择的材料副本、完成待办、哈希、警告和是否使用 AI。

默认不导出：API Key、绝对路径、Windows 用户名、历史样本文本、AI 原始请求/响应、标记为 `sensitive` 的事实值。

用户仍需在分享 ZIP 前检查其中主动加入的照片、票据和文案内容。
